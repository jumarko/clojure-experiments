# clojure-experiments

My Clojure REPL experiments. Instead of typing directly into REPL, save everything in the file! 
Motivated by Stuart Halloway's talk about REPL Driven Development: https://vimeo.com/223309989

## Books

Code examples from various books are [here](src/clojure_experiments/books).
Lots of them are incomplete but [**Joy of Clojure**](src/clojure_experiments/books/joy_of_clojure) is complete.
